# OrderSphere — Order Management System

A console-based Order Management System developed using C++ to manage customer orders efficiently.

## Features
- Add new customer orders
- View all orders
- Search orders by order number
- Delete orders
- Input validation for numeric fields and contact numbers
- File handling to save and load order records

## Technologies Used
- C++
- STL (`vector`)
- File Handling
- Input Validation

## How to Run
1. Clone or download this repository.
2. Open `OrderSphere.cpp` in a C++ IDE or editor.
3. Compile the program using a C++ compiler.
4. Run the generated executable.

- Practiced CRUD operations
